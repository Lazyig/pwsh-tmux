# pwsh-tmux

A terminal multiplexer that follows tmux's commands, key bindings, options, formats and
config syntax, written in Rust for **Windows** (ConPTY + named pipes) and **Linux/Unix**
(pty + Unix sockets). The default shell is PowerShell (`pwsh`, falling back to
`powershell.exe` on Windows; `pwsh`, then `$SHELL` on Unix).

It is an independent reimplementation, not a port: it contains no tmux source code and is
not affiliated with the tmux project.

## Install

Download a binary from the releases page, or build it:

```
cargo build --release
# target/release/pwsh-tmux(.exe) — put it on PATH (optionally alias it to `tmux`)
```

Windows binaries can be built with `RUSTFLAGS="-C target-feature=+crt-static"` so they don't
need the Visual C++ runtime.

## Usage

It works like tmux:

```
pwsh-tmux                         # new session, attached
pwsh-tmux new -s work -d          # detached session
pwsh-tmux attach -t work          # (alias: a / at)
pwsh-tmux ls
pwsh-tmux split-window -h -t work
pwsh-tmux send-keys -t work 'Get-Date' Enter
pwsh-tmux capture-pane -p -t work
pwsh-tmux list-keys               # all bindings, prefix C-b
pwsh-tmux list-commands
```

Global flags: `-L socket-name`, `-S socket-path`, `-f config`, `-N` (don't start a server),
`-c shell-command`, `-C`/`-CC` (control mode), `-T features`, `-V`.

Configuration: `~/.pwsh-tmux.conf` or `~/.config/pwsh-tmux/pwsh-tmux.conf`, in tmux syntax
(`set -g`, `bind`, `{ }` blocks, `\;`, `%if/%else/%endif`, `source-file`, ...). To reuse a tmux
config, put `source-file ~/.tmux.conf` in it.

Environment: `PWSH_TMUX_SHELL` overrides the default shell; `PWSH_TMUX_NO_HOOK=1` disables the
PowerShell prompt hook described below.

## Features

- **Sessions, windows, panes**: about 90 tmux commands — new/attach/detach/switch sessions;
  split/kill/select/resize/swap/rotate/break/join/move panes; new/kill/move/swap/link/unlink/
  rename/find windows; respawn, `remain-on-exit`, `synchronize-panes`, `pipe-pane`, marked pane,
  zoom; session groups (`new-session -t`).
- **Targets**: `session:window.pane`, `$id @id %id`, `{last} {next} {previous} {top} {left}
  {marked} {mouse}` ..., `+N/-N`, name prefixes and globs.
- **Layouts**: even-horizontal/vertical, main-horizontal/vertical, tiled, `next-layout`,
  `select-layout -E`, tmux layout strings (`#{window_layout}` round-trips).
- **Key tables**: tmux's default `prefix`, `root`, `copy-mode` and `copy-mode-vi` tables,
  `bind -n/-r/-T/-N`, `unbind`, `switch-client -T`, `prefix2`, repeat-time, extended keys
  (`extended-keys`, `extended-keys-format`).
- **Copy mode** (emacs and vi keys): motions, word/line/rectangle selection, search, jumps,
  counts, `copy-pipe`, mouse selection; copied text goes to a paste buffer and to the terminal
  clipboard (OSC 52).
- **Buffers**: set/show/list/delete/save/load/paste/choose-buffer.
- **Formats**: `#{...}` variables, conditionals, comparisons, modifiers (`=N`, `s///`, `b:`, `t:`,
  `e|+|`, `m:` ...), strftime, `#[style]`, `#(command)`. The status line is built from
  `status-left`, `window-status(-current)-format`, `status-right` and `status-format[]`.
- **Options**: server/session/window/pane scopes, `set -g/-w/-s/-p/-u/-a/-o/-q/-F`,
  `show -A/-v/-g`, user `@options`.
- **Interactive**: command prompt (history, completion), confirm-before, choose-tree /
  choose-client / customize-mode, display-menu, display-popup, display-panes, clock-mode,
  messages, `pane-border-status`.
- **Mouse** (`set -g mouse on`): select panes and windows, drag borders, wheel into copy mode,
  drag selection, double/triple click, right-click menus.
- **Scripting**: hooks (`set-hook`, `after-*`, `client-attached`, `pane-exited`, ...),
  `run-shell`, `if-shell`, `wait-for`, `set-environment`, `update-environment`, alerts.
- **Terminal features** (`terminal-features`, `-T`): per-client RGB / 256 / 16-colour output,
  synchronized output, clipboard, title, cursor style, focus and mouse.
- **Control mode** (`-C`, `-CC`): `%begin/%end/%error`, `%output`, notifications
  (`%window-add`, `%layout-change`, `%session-changed`, ...), flow control
  (`refresh-client -f pause-after=N`, `-A %pane:pause|continue`) and subscriptions (`-B`).
- **server-access**: let other users attach (`-S <socket>`), optionally read-only. On Windows
  the named pipe's ACL is created when the server starts, so put `server-access -a user` in the
  config file.
- **Platform details**: on Windows `#{pane_current_path}` comes from an OSC 7 prompt hook that
  is injected into PowerShell, and `#{pane_current_command}` / automatic-rename come from the
  shell's descendant processes. On Unix they come from `/proc` and the pty's foreground process
  group.

## Limits

- Window sizes are capped at 1000x1000: the terminal emulator allocates every cell up front
  (tmux allows 10000).
- On Windows `suspend-client` does nothing (no job control) and `lock-*` needs `lock-command`.
- Not implemented: a few copy-mode commands (bracket matching, true incremental search), the
  `S:`/`W:`/`P:` loop and `C:` format modifiers, and back-references in `s///`.

## Tests

```

```

`tests/multiuser.sh` exercises `server-access` between real Unix users (run it as root in a
throwaway container).
